# Пример Summary для резюме

Summary — 3–5 предложений, начинается с роли, факты под вакансию. Ниже два варианта одних и тех же фактов: скилл адаптирует акценты под тип вакансии (раздел 3 `skills/job-apply/SKILL.md`), не меняя сами факты — они одни и те же, из памяти.

## Вариант «бизнесовая вакансия»

> Product Owner внутренней AI-платформы в банке из ТОП-5. Построил платформу с нуля: кросс-функциональная команда ~20 человек, платформу используют 300+ команд бизнеса. Автоматизация целевых процессов выросла с 0 до 90% — семизначная годовая экономия. До этого — банковские сервисы с измеримым эффектом: срок доставки карты 2–3 дня → 1 день, NPS канала заказа наличных +2 п.п. после внедрения DS-модели. 20 лет в продуктах и клиентском опыте: банкинг, сервис такси (поддержка 80+), DIY-ритейл (NPS доставки 75 → 82). Магистр ВШЭ, экономика и социология.

Техника убрана: нет API, архитектуры, промпт-инжиниринга. Оставлен уровень продуктовой аналитики.

## Вариант «техническая/платформенная вакансия»

> Product Owner внутренней AI-платформы в банке из ТОП-5: no-code конструктор сценариев автоматизации, AI-агенты, интеграции по API. Команда ~20 человек, 300+ команд-потребителей, покрытие целевых сценариев автоматизации 0 → 90%, семизначная годовая экономия. Ранее — кассово-платёжные сервисы: интеграции, DS-модель заказа наличных (NPS +2 п.п.), сжатие срока доставки карты до 1 дня. Сервис такси: система выявления мошенничества, поддержка 80+. Магистр ВШЭ, экономика и социология.

Добавлены конструктор, агенты, интеграции, антифрод — всё из памяти, ничего нового не появилось.

## Что проверяется

- Каждый факт ← конкретный пункт памяти; количество команд не попало в Summary (правило вёрстки)
- Цифры не «улучшились» при адаптации: 0→90% одинаковы в обоих вариантах
- Сумм нет — только «семизначная» (NDA)
- Стоп-лист соблюдён: без «вдохновлён», без эмоциональной мишуры
