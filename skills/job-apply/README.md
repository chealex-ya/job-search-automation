# job-apply

Скилл для Claude Code: оформление отклика на вакансию — от ссылки на сайте работодателя до папки с адаптированным резюме и follow-up письмом рекрутеру.

Персональные данные в скилл не зашиты: факты берутся из [`memory/memory.md`](../../memory/memory.md), правила генерации — из [`constraints.md`](../../constraints.md). Это и есть защита от галлюцинаций: скилл собирает артефакты из памяти, а не сочиняет.

## Что делает

- Забирает описание вакансии с сайта работодателя (curl + разбор Next.js-разметки) и сохраняет в `vacancy.json`
- Создаёт папку вакансии в рабочем каталоге
- Генерирует адаптированное под тип вакансии резюме (HTML, print-ready A4)
- Пишет follow-up письмо рекрутеру по шаблону владельца
- Прогоняет чек-лист перед сдачей — включая трассировку каждого факта до памяти

## Установка

1. Клонируйте репозиторий и заполните `memory/memory.md` под себя.
2. Скопируйте папку скилла в `.claude/skills/` (в корне клона, чтобы скилл видел память и контракт):

   ```
   job-search-automation/.claude/skills/job-apply/SKILL.md
   ```

После этого скилл доступен в Claude Code как `/job-apply`. В аргументе можно сразу передать ссылку на вакансию:

```
/job-apply https://<карьерный-сайт-работодателя>/vacancies/...
```

## Требования

- curl (входит в Windows 10/11 и Git for Windows)
- Python 3 (разбор JSON со страницы вакансии)

## Почему curl, а не WebFetch

Карьерные сайты российских компаний часто отдают сертификаты, которые не проходят стандартные проверки, и рендерят контент JavaScript'ом. Скилл использует `curl -sk` и разбирает Next.js-разметку напрямую — подробности в `SKILL.md`, раздел 1. Не-Next.js сайты обрабатываются текстом от владельца.
