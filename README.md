# job-search-automation

Автоматизация отклика на вакансии с гарантиями от галлюцинаций: агент (Claude Code или любой другой) собирает сквозной отклик — от ссылки на вакансию до адаптированного резюме и письма рекрутеру — **не сочиняя ни одного факта**.

Ключевая идея — **заземление генерации**:

```
memory/memory.md  →  единственный источник фактов обо мне
vacancy.json      →  единственный источник фактов о вакансии
constraints.md    →  контракт: что LLM делать обязана и что ей запрещено
skills/job-apply  →  сквозной процесс: вакансия → папка → резюме → письмо
examples/         →  как выглядит результат
```

LLM не «пишет обо мне» — она **собирает** артефакты из памяти по правилам. Факт, которого нет в памяти, не появляется нигде.

## Чек-лист аудита (проверяйте меня)

Если вы рекрутер (или просто скептик) — вот три вопроса, которые стоит задать любой «автоматизации поиска работы», и как на них отвечает этот репозиторий:

### 1. Уровень: сквозной процесс или скрипт-затычка?

Один скрипт, который что-то генерит — не автоматизация. Здесь процесс целиком: забор вакансии с сайта работодателя → структурированный `vacancy.json` → папка вакансии → адаптированное под тип вакансии резюме (бизнес/техника) → follow-up письмо рекрутеру → чек-лист перед сдачей. Кусочная автоматизация у кандидата = кусочная в его работе.

### 2. Промпты: прописано ли, что нельзя выдумывать?

Да, отдельным контрактом — [`constraints.md`](constraints.md): запрет выдуманных метрик и сроков, запрет усиливать формулировки («участвовал» → «руководил»), запрет абсолютных сумм (только относительные — «семизначная годовая экономия»), обязанность ставить `<TODO: подтвердить>` вместо додумывания. Память фактов — [`memory/memory.md`](memory/memory.md).

### 3. Границы: что автоматизация НЕ делает?

- **Не отправляет** письма и **не откликается** на сайтах — финальное действие всегда за человеком
- Не выдумывает факты — только переносит из памяти
- Не решает, куда откликаться — выбор вакансий за человеком
- Отклик на сайте работодателя — вручную (письмо — приложение к нему)

## Быстрый старт

1. Склонируйте репозиторий и заполните `memory/memory.md` под себя (структура и пример — внутри).
2. Скопируйте `skills/job-apply/` в `.claude/skills/` вашего проекта.
3. Запускайте в Claude Code: `/job-apply <ссылка на вакансию>`.

Требования: curl и Python 3 (разбор страницы вакансии).
