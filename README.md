# job-search-automation

Автоматизация рутинной части отклика на вакансии: от ссылки на вакансию до папки с адаптированным резюме и follow-up письмом рекрутеру. Рантайм — Claude Code (механика skills); подойдёт любой агент с доступом к файлам и shell.

## Откуда берутся вакансии

Вход единый для любого источника — ссылка на страницу вакансии или текст:

- карьерные сайты компаний — забираются автоматически (см. «Стек»);
- джоб-борды, LinkedIn, телеграм-каналы, рекомендации — копированием текста вакансии.

Каждая вакансия сохраняется локально как `vacancy.json` — снимок исходного описания. Дальше вся генерация опирается на этот снимок, а не на страницу, которая может измениться или исчезнуть.

## Процесс

```
ссылка/текст вакансии
        │
        ▼
   vacancy.json ──► папка вакансии
                        ├── Резюме — <имя>.html     (адаптированное)
                        ├── Follow-up письмо.md      (рекрутеру)
                        └── vacancy.json             (исходник)
        │
        ▼
   чек-лист → отправка вручную
```

1. **Забор вакансии.** curl с `-sk` (карьерные сайты российских компаний часто отдают сертификаты, не проходящие проверку, и рендерят контент JS'ом); для сайтов на Next.js данные выдёргиваются из `__NEXT_DATA__` python-скриптом.
2. **Резюме.** адаптация базового HTML под тип вакансии: «бизнесовые» — без техники, технические — с интеграциями и архитектурой. Вёрстка под печать A4.
3. **Письмо.** follow-up рекрутеру (контакт — из вакансии): 150–200 слов, 3–4 буллета, одна сильная связка метрик.
4. **Чек-лист.** прогон перед сдачей, включая трассировку фактов (см. ниже). Отправка — всегда вручную: на сайте и почтой.

## Архитектура

| Путь | Назначение |
|---|---|
| [`memory/memory.md`](memory/memory.md) | мастер-профиль: факты о кандидате, устойчивые формулировки, стоп-лист |
| [`constraints.md`](constraints.md) | ограничения для LLM: источники фактов, запреты, границы |
| [`skills/job-apply/`](skills/job-apply/) | скилл Claude Code — сквозной процесс выше |
| [`examples/`](examples/) | примеры сгенерированных артефактов |

Генерация заземлена на два источника: `memory/memory.md` (факты о кандидате) и `vacancy.json` (факты о вакансии). Чего нет в них — не используется: вместо додумывания ставится `<TODO: подтвердить>`, числа не «улучшаются», формулировки из стоп-листа не проходят. Ограничения собраны в [`constraints.md`](constraints.md).

## Быстрый старт

1. Клонируйте репозиторий, заполните `memory/memory.md` под себя.
2. Скопируйте `skills/job-apply/` в `.claude/skills/` в корне клона.
3. В Claude Code: `/job-apply <ссылка на вакансию>`.

Требования: curl, Python 3.
