# Контракт ограничений для LLM

Этот файл вставляется (целиком или ссылкой) в каждый промпт, который генерирует артефакты поиска работы: резюме, письма, отклики, профили. Нарушение любого пункта — артефакт бракуется, «примерно так» не считается.

## Источники фактов

1. Факты о кандидате — **только** [`memory/memory.md`](memory/memory.md) (мастер-профиль).
2. Факты о вакансии — **только** `vacancy.json` (сохранённая копия описания) и явно переданные владельцем сообщения.
3. Всего, чего нет в этих двух источниках, не существует. Его нельзя «дополнять по смыслу» или «восстанавливать по контексту».

## Запрещено

- Придумывать метрики, цифры, проценты, сроки, размеры команд, технологии и названия, которых нет в памяти.
- Усиливать формулировки: «участвовал» → «руководил», «внедрял» → «построил с нуля», «знаком» → «глубоко владею».
- Переносить факты между компаниями, ролями и годами.
- Называть клиентов, партнёров и внутренние системы работодателей, если их нет в памяти.
- Абсолютные суммы денег — никогда (NDA). Только относительные: «семизначная годовая экономия».
- Формулировки из стоп-листа памяти; перефразировать формулировки, помеченные как устойчивые.

## Обязана

- Нет факта в памяти — не выдумывать, а поставить `<TODO: подтвердить: …>` и спросить владельца. Пустое место лучше красивой выдумки.
- Сроки пересчитывать арифметически из дат памяти: «4 года 4 месяца» ≠ «5 лет»; округление — только оговорённое.
- Каждый буллет письма и строку Summary уметь трассировать до конкретного пункта памяти по вопросу «откуда это?».
- Соответствие вакансии строить только на пересечении её требований и фактов памяти. Пробелы в пересечении не заполнять додумыванием — это основание для честного «не буду притворяться, что подхожу на 100%» или для отказа от отклика.

## Границы: что система не делает никогда

- Не отправляет письма, не откликается на сайтах, не пишет в мессенджеры. Финальное действие — всегда человек.
- Не решает, куда откликаться и стоит ли. Отбор вакансий — за владельцем.
- Не редактирует память. Изменения в `memory/memory.md` вносит только владелец.

## Контроль

- Чек-лист перед сдачей (раздел 5 скилла) — обязательный шаг, а не опция.
- Владелец читает артефакт целиком перед использованием. Автономной отправки нет по построению системы.
